# THR Enterprise v5.10

Versão com ambiente próprio para **Suporte Regional** e leitura da regional a partir da coluna **Folha** da base Excel.

## Usuários padrão

- **admin** / PIN **1234** — Perfil Admin
- **rh** / PIN **1234** — Perfil RH/DP
- **suporte** / PIN **1234** — Perfil Suporte Regional

## Perfil Suporte Regional

O Suporte Regional agora possui ambiente próprio:

1. **Home**
2. **Importar Base**
3. **Nova Solicitação**
4. **Minhas Solicitações**

Ele não acessa Processos pelo menu lateral, relatórios, auditoria, configurações, backup, usuários, dossiê, timeline ou biblioteca.

## Regional do colaborador

A coluna **Folha** da planilha passa a ser usada como **Regional / Folha** do colaborador.

Ao gerar documentos, o THR registra:

- usuário emissor;
- perfil;
- regional do usuário;
- regional/folha do colaborador;
- protocolo.

## Base incluída

O pacote já inclui a planilha atualizada enviada pelo usuário em `data/QUADRO GERAL.xlsm`.
