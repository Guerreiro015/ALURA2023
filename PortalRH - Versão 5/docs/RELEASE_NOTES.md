# Release Notes — THR Enterprise v5.7

Esta versão refinou a experiência da tela inicial. O antigo Dashboard foi renomeado para **Home** e agora mantém apenas informações executivas: indicadores gerais, Meu Dia, Alertas RH, ações rápidas, pesquisa, ficha do colaborador e favoritos.

A Central de Notificações foi removida do topo para evitar duplicidade com Alertas RH. O Dashboard Vivo foi movido para a tela Processos, onde os indicadores por processo fazem mais sentido.
