# Changelog — THR Enterprise v5.10

## Novidades

- Ambiente simplificado para **Suporte Regional**.
- Menu lateral do Suporte agora mostra apenas: Home, Importar Base, Nova Solicitação e Minhas Solicitações.
- Removido **Processos** do menu lateral para o perfil Suporte Regional.
- Suporte Regional agora possui permissão para **Importar Base**.
- A coluna **Folha** passou a ser tratada como **Regional / Folha** do colaborador.
- Documentos gerados exibem emissor, perfil e regional.
- Histórico registra `regionalUsuario` e `regionalColaborador`.
- Administração de usuários agora possui campo **Regional**.

## Ajustes

- Perfil antigo `Suporte` é migrado automaticamente para `Suporte Regional`.
- Perfil `Consulta` permanece removido.
- A base Excel atualizada foi incorporada ao pacote.
